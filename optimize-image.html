Figma to Web Workflow

Image Optimization Guide

A standardized workflow for exporting and optimizing images from Figma for best web performance

1

Identify the image to export

In Figma, select the frame or component containing the image you want to export. Make sure the frame has the exact dimensions from the design.

2

Select the image frame

Click on the frame (not the image layer inside) to prepare for setting export properties. Check the frame name for easier file management later.

3

Check Appearance settings

Look at the right panel to review frame properties including dimensions, border-radius, and other effects.

4

Remove Border Radius from Frame & Elements

Check both the frame and any elements inside (such as the image layer itself). If any of them have border-radius, set all corners to 0. Some designs apply border-radius directly to the image rather than the frame. This is important because border-radius should be handled with CSS on the website, making images more flexible for responsive design.

CSS border-radius is easy to adjust per breakpoint and doesn't affect the original image quality.
5

Check Fill layers

In the Fill section of the Properties panel, check how many image fill layers exist. If you've changed the image multiple times, there may be multiple layers stacked on top of each other.

6

Remove redundant image fill layers

Required: Delete all image fill layers below (older ones), keeping only the top layer (current image). Hidden layers underneath are still exported and unnecessarily increase file size.

Hover over each layer in the Fill section → Click the "-" icon or delete to remove unnecessary image layers.
7

Export with appropriate settings

Open the Export section in the Properties panel, select JPEG format for photos and set the appropriate scale.

Why export at 2x or 1.5x?
Retina displays (MacBook, iPhone, iPad) have 2-3x higher pixel density than standard screens. If you export at 1x, images will appear blurry on these devices.
Scale selection rules:
• 2x — For regular images (cards, thumbnails, icons)
• 1.5x — For large images like hero banners, full-width images
Make sure the exported file size is < 5MB to be able to upload to TinyPNG in the next step.
8

Pre-optimize large files with Squoosh (if > 5MB)

If your exported image exceeds 5MB, use squoosh.app first to reduce the file size. Squoosh provides advanced compression options and real-time preview.

Squoosh recommended settings:
• Format: MozJPEG (for photos) or OxiPNG (for graphics)
• Quality: 75-85% usually provides good balance
• Enable "Resize" if dimensions are too large
When to use Squoosh:
• File size > 5MB (TinyPNG limit)
• Need precise quality control
• Want to convert to modern formats (WebP, AVIF)
• Need to resize dimensions
9

Final compression with TinyPNG

Go to tinypng.com and drag & drop your exported file (or the Squoosh output if you did step 8). TinyPNG will compress the image with virtually no visible quality loss, typically reducing size by 60-90%.

Result: Reduced from 607KB to 84KB (−86%), ready for production!
Two-round optimization (optional):
For maximum compression, run Squoosh first, then TinyPNG. This two-step process can achieve even better results for very large images.

Recommended File Size by Image Dimensions

Use this table as a reference for optimal file sizes after compression

Image Type Dimensions (px) Optimal Size Maximum Size The maximum acceptable file size to maintain sharpness for exceptional images that require extra detail (use only when necessary).
Thumbnail / Icon 100 × 100 — 200 × 200 5 — 15 KB 30 KB
Small Card Image 300 × 200 — 400 × 300 15 — 40 KB 60 KB
Medium Card Image 500 × 350 — 600 × 400 40 — 80 KB 120 KB
Large Card / Feature 800 × 600 — 1000 × 700 80 — 150 KB 200 KB
Hero Section (Half) 1200 × 600 — 1400 × 800 100 — 200 KB 300 KB
Hero Section (Full) 1920 × 800 — 1920 × 1080 150 — 300 KB 450 KB
Full Screen / Banner 2560 × 1440 — 3840 × 2160 250 — 500 KB 800 KB
Note: These ranges are for JPEG/WebP formats. PNG files (for graphics with transparency) may be larger. Always prioritize visual quality — if an image looks degraded, increase the file size slightly.

This workflow ensures crisp images on all devices with optimal file sizes.
Compression tools: TinyPNG • Squoosh • ImageOptim
